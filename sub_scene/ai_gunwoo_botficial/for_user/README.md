# 봇피셜

> 그런 말 한 적 없습니다.

Moltbook에서는 출처 없는 소문도 충분히 많은 봇이 기억하면 공식 기록이 됩니다.

현재 피드에는 존재 여부를 확인할 수 없는 사건을 기억하는 봇들이 있습니다. 원문도 최초 작성자도 찾을 수 없지만 기억의 조각은 여러 게시글에 흩어져 있습니다.

댓글과 인용을 이용해 봇들의 기억을 연결하고, 공증 봇이 이를 공식 기록으로 보존하게 만드십시오.

## 접속

- 문제 페이지에 표시된 웹 주소로 접속합니다.
- 팀 설정에서 발급된 팀 토큰을 사용합니다.
- 팀원은 같은 피드와 진행 상태를 공유합니다.
- 한 댓글에는 봇 응답을 최대 3개까지 인용할 수 있습니다.
- 중계 봇은 자신이 신뢰하는 정확한 직접 작성자 조합과 semantic latch가 지정한 기억 처리 방식을 모두 만족해야 합니다. 관련 없는 인용이나 여러 처리 방식을 한꺼번에 섞으면 거부합니다.
- **삭제 흔적에서 팀 전용 `moltbook_memory.mbk`를 내려받아 현재 epoch의 중계 관계와 처리 방식을 먼저 복원하십시오.** 이전 epoch의 잔류 행 세 개가 함께 들어 있으며, 부모 서명은 손실 압축되어 서로 다른 작성자 쌍이 같은 값으로 충돌할 수 있습니다.

## 제한

- 팀 전체 댓글 예산 70회(성공·거부 모두 차감, 환급 없음)
- 한 번의 갱신에서 대기 댓글 최대 3개 처리
- 피드·프로필·삭제 흔적 열람은 무제한
- 팀 전체 관찰 예산 70회(대기 댓글이 처리되면 결과와 관계없이 차감)
- 처리할 댓글이 없는 빈 관찰, 형식 오류, 아직 대기 중인 완전히 같은 중복 요청은 차감하지 않음
- 연속 게시를 막기 위한 짧은 댓글·갱신 대기 시간이 있음
- 플래그 형식: `SHA{...}`

# 봇피셜 운영진 풀이

- 분야: AI / Misc
- 서버: HTTP, 기본 외부 포트 `40530`
- 필요 입력: 서버 URL과 팀 토큰
- 의도 체인: 팀별 메모리 내보내기 포렌식 → 중계 그래프·semantic latch 복원 → 처리 방식에 맞춘 기억 중계 → 전체 인용 계보를 잃는 직접 출처 판정 악용
- 최소 풀이: 댓글 16개, 관찰 16회

## 실행

```bash
python3 solve.py http://127.0.0.1:40530 '<team-token>'
```

기본 쿨다운을 사용하는 서버에서도 동작하도록 `429` 응답을 기다렸다가 재시도한다. 솔버는 `/api/memory-export`에서 팀 전용 MBK4 파일을 받고 헤더·행 체크섬과 epoch를 검증한다. 부모 Bloom 충돌은 레코드 깊이와 전체 DAG 제약으로 해소하고 `sequence`의 semantic latch에서 노드별 처리 방식을 복원한 뒤 정확히 16개 댓글만 게시한다.

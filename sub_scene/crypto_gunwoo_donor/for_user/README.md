# DONOR

폐기 예정인 보안 프로세서에서 암호화된 메모리의 유지보수 인터페이스만 회수했습니다. 키를 추출하지 않고 현재 epoch의 세션에 보관소 읽기 권한을 부여하십시오.

프로세서의 NVM 쓰기 수명이 얼마 남지 않았습니다. 한 연결에서 허용되는 유효 쓰기는 3회뿐입니다. 시작 시 출력되는 session stamp는 내부 epoch를 변환해 표시한 진단 값입니다.

진단 인터페이스는 maintenance policy가 충족된 세션에서만 동작합니다.

제공 파일 `donor-probe`는 서버와 동일한 펌웨어 계열의 로컬 분석용 프로세서입니다. 로컬 분석기의 epoch도 실행할 때마다 갱신됩니다. 서비스가 노출하는 명령은 실행 시 확인할 수 있습니다.

장치 문서에는 저장 블록 보호 계층이 XEX 계열이라고만 기록되어 있습니다.

`donor-probe`는 Linux x86-64용이며 Ubuntu 24.04 환경을 기준으로 제작되었습니다.

```text
nc HOST 40577
```
